## 3. Reactions and reposts — IDs only

LinkedIn's `Reactions.csv` and `InstantReposts.csv` exports include only `Date / Type / Link` — **no post text, no author**. So we can't programmatically filter to "buildathon-related" reactions. What we have:

- **~120+ reactions** in the Apr 22 – May 5 window (full list in `linkedin-raw.md`)
- **9 reposts** in the same window

Many are probably student-authored buildathon posts (Vishal liked / reposted them in real time during the event), but each URL must be opened to confirm. Two ways forward:

1. **Manual:** open the raw URL list and triage.
2. **Automated:** use Chrome browser automation (`mcp__claude-in-chrome__*`) to fetch each post, extract author + text, then filter to event-related ones. ~150 fetches × ~2s each. Doable in one session but rate-limit-sensitive.

Recommend option 2 as a follow-up if the report needs comprehensive student attribution.

## 5. What's NOT in this dataset

- Engagement counts on Vishal's own posts (likes/comments-received) — to attribute reach you'd need to fetch each post page.
- Media (images/videos attached to posts) — LinkedIn omits media URLs from exports.
- Posts authored by **other people** about the event (students, organizers, judges) — the export only contains Vishal's own activity. To pull those, search LinkedIn directly with hashtags `#GiesAIforImpact`, `#MsbaAtGies`, `#BuildToLearn` or scrape the `linkedin.com/feed/hashtag/` pages.
